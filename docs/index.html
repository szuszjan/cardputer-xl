M5Stack Cardputer-ADV Firmware

CARDPUTERXL

A single-file "OS"/app launcher for the Cardputer-ADV — one big firmware image instead of a collection of separate apps. Around 30 built-in apps: system tools, a CardC scripting IDE, a full 3D kart racer and a vector flight sim, Wi-Fi and BLE tools, an encrypted code vault, and a floating quick-launch menu that pops up over anything.

Flash it from your browser

No Arduino IDE, no drivers — Web Serial flashes the merged firmware image straight from this page.

v1.2.0 · ESP32-S3 · 4 MB image Your browser doesn't support Web Serial. Open this page in Chrome or Edge on a desktop (not available on iOS, and not yet in Firefox/Safari). Web Serial needs HTTPS — you're fine on this page, but a local copy over plain http:// won't work.

Plug the Cardputer-ADV in over USB-C, click the button above, and pick its serial port when Chrome/Edge asks. This writes the full v1.2.0 merged image (bootloader + partitions + app in one file) starting at offset 0 — it replaces whatever firmware is currently on the device. Hold ` at power-on afterwards if you ever need Recovery Mode (reboot / factory reset / hardware self-test).

Controls

The Cardputer's ; , . / keys double as printed directional arrows (up/left/down/right). A few keys work globally, from any app:

KeyAction
FnBack / cancel — closes dialogs, returns to Home
OptToggle the floating quick-launch menu
Ctrl+FFavourite / unfavourite the current app
` at power-onRecovery Mode — reboot, factory reset, hardware self-test

Build it yourself

The firmware is one Arduino sketch. Board: esp32:esp32:m5stack_cardputer (arduino-esp32 core 3.x) — it needs the "Huge APP (3MB No OTA/1MB SPIFFS)" partition scheme, since it doesn't fit in the default 1.2 MB app partition.

arduino-cli compile --upload -p <PORT> \
  --fqbn esp32:esp32:m5stack_cardputer:PartitionScheme=huge_app CardputerXL

Full library list, wiring table, and the rendering/architecture notes are in the README.
